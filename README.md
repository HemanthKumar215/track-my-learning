# Track My Learning: Java DSA

My day-by-day preparation for software engineering placements: Java fundamentals → DSA patterns → LeetCode Easy, Medium and Hard. All code is Java 15 compatible.

Every solution file starts with the **question**, examples, my **approach**, **time/space complexity**, my **status** and the **mistakes I made** along the way, followed by the code and a `main` method that runs the examples.

**Status labels**
- **Independent**: solved without hints
- **Hint-assisted**: solved with guidance
- **Reviewed**: understood a solution but not yet reproduced it myself
- **Needs revision**: still struggling with the concept
